The Dolphin model by Eric Hartford, based on [Mistral](https://ollama.ai/library/mistral) version 0.2 released in March 2024. This model is uncensored, available for both commercial and non-commercial use, and excels at coding.

## Versions

| Tag | Date | Notes |
| --- | --- | --- |
| `v2.8` `latest` | 03/31/2024 | Based on Mistral 0.2 with support for a context window of 32K tokens. |

| `v2.2.1` | 10/30/2023 | This is a checkpoint release, to fix overfit training |
