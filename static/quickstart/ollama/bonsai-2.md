Bonsai 2 from [Prism ML](https://prismml.com/) is a family of vision models built for ternary weights (−1, 0 or +1): about half the size of standard 4-bit models, at close to full-precision quality.

All sizes support thinking, tool calling, image input and a 262K-token context window.
