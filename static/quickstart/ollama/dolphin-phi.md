Dolphin Phi 2.6 is an uncensored model based on the 2.7B [Phi](https://ollama.ai/library/phi) model by Microsoft Research, using similar datasets as other versions of this model such as [Dolphin Mixtral](https://ollama.ai/library/dolphin-mixtral).

It was created by [Eric Hartford](https://erichartford.com/) and Cognitive Computations.
